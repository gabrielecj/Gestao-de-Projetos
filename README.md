# 03-gestao-de-projetos

Projeto autoral de portfólio UI/UX + full stack.

## Executar
Requer Python 3.10+ e não exige bibliotecas externas.

```bash
cd backend
python server.py
```

Abra `http://127.0.0.1:5003`.

O SQLite é criado automaticamente e recebe dados seed na primeira execução.

## Arquitetura
`frontend/` = HTML, CSS e JavaScript.
`backend/server.py` = API REST + servidor.
`backend/schema.sql` = banco SQLite.

## Portfólio
Os dados seed são fictícios. Para a apresentação UI/UX, documente também problema, persona, jornada, arquitetura, wireframes, guia de estilo, protótipo de alta fidelidade e validação.
